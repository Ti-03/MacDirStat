See where your disk space went.

MacDirStat scans any folder and turns your filesystem into a beautiful, interactive visualization. Find duplicates, delete what you don't need, reclaim your space.

Features

Everything you need to reclaim your disk

🗺️

Sunburst Treemap

Every file and folder visualized as an arc sized by disk usage. Depth rings show hierarchy at a glance.

🔍

Duplicate Detection

Finds identical files by content hash and shows exactly how much space they waste. Delete all copies in one click.

🗂️

File Type Breakdown

See which file types are eating your space — videos, code, archives, images — color-coded and searchable.

🖱️

Drill Navigation

Click any folder to zoom in. Click back to go up. Navigate your disk like a map.

🗑️

Delete Right Here

Right-click any file or arc to move it to Trash. The chart updates instantly — no need to open Finder.

⌨️

Force Touch Haptics

Feel the weight of files through your trackpad. Large files give stronger feedback. A detail that matters.

Built Different

Pure Swift. No Electron. No web views.

ScannerPOSIX opendir/fstatat with async task groups — parallel, cancellable
RendererSwiftUI Canvas — draws 1,000+ arcs at 30 fps
DuplicatesSHA-256 content hashing on a background actor
HapticsNSHapticFeedbackManager — intensity scales with file size
Privacy100% on-device. Zero network access. Zero tracking.
